# clash-of-clans-upgrade-planner
A Python tool that tracks Clash of Clans upgrades and recommends what to prioritize.


Clash of Clans Upgrade Planner

Project Goal
Create a Python program that helps Clash of Clans players track their upgrade progress and decide which upgrades to prioritize.

MVP Features
- Retrieve player stats using the official Clash of Clans API.
- Display hero, troop, and spell levels.
- Compare current levels with Town Hall-specific maximum levels.
- Recommend upgrades based on player preferences.

Future Plans
- Calculate upgrade costs and completion times.
- Create upgrade schedules based on available builders.
- Track defense and wall upgrades.
- Save player progress over time.

Tech Stack
- Language: Python 3
- Libraries: requests, json, os
- Tools: Git, GitHub, curl, Terminal
- Data Storage: JSON files
- Data Source: Official Clash of Clans API
